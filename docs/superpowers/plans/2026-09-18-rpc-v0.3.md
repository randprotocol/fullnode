# RPC v0.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eleven new `rand_*` JSON-RPC methods and two WebSocket topics, node-only, tagged `v0.3`.

**Architecture:** Every method is a new arm in the `dispatch` match in `crates/randprotocol-node/src/rpc.rs`, reading storage directly where it can and sending a `NodeCommand` with a `oneshot` reply where the answer lives in the node loop (mempool, refused cache, HotStuff). One new RocksDB column family indexes receipts by program. Two new broadcast channels next to `heads` carry commits and refusals to the WebSocket task in `ws.rs`.

**Tech Stack:** Rust, tokio, axum, rocksdb, serde_json, bincode. Tests are the crate's existing `#[tokio::test]` harness (`state_for`, `state_over`, `call`, `ok`) and the storage fixtures (`genesis_with`, `alloc_note`, `make_block`, `chain_fixture`).

**Spec:** `docs/superpowers/specs/2026-09-18-rpc-v0.3-design.md`

## Global Constraints

- No consensus, wire-format, genesis or storage-key change to any existing family. Chain 12 keeps running; the fleet updates with `deploy/update-droplet.sh`.
- Every existing method, error code and subscription keeps its shape. `rand_getWitness` stays.
- Error codes: `-32602` bad parameter, `-32000` refusal (`RpcError::rejected`), `-32601` unknown method. Amounts are strings, hashes and roots hex.
- Caps, verbatim from the spec §5: 64 hashes per `rand_getTransactionStatus`, 32 indices per `rand_getWitnesses`, 256 receipts per `rand_getReceipts` page, 128 headers per `rand_getBlocks`, 64 views per `rand_getProposer`, `MAX_WS_SUBSCRIPTIONS` = 8 unchanged.
- Linear history: commit on a branch `rpc-v0.4`, rebase onto `main`, fast-forward, never a merge commit. Commit messages end with the session's `Co-Authored-By` line.
- Run `cargo test -p randprotocol-node --lib` after every task. The aggregation tests that need `RECURSION_FIXTURES` are skipped on the laptop and run on E at rollout.
- `cargo fmt` before each commit; `cargo clippy -p randprotocol-node` clean of new warnings.

//! Captures the git commit the node was built from, for `rand_getVersion`. A checkout answers
//! `git rev-parse HEAD`; a deploy worktree without `.git` answers the `.git-rev` file the
//! deploy scripts write at the workspace root; anything else is "unknown".
use std::path::Path;
use std::process::Command;

fn main() {
    let root = Path::new(env!("CARGO_MANIFEST_DIR")).join("../..");
    let git = |args: &[&str]| {
        Command::new("git").args(args).current_dir(&root).output().ok()
            .filter(|o| o.status.success())
            .map(|o| String::from_utf8_lossy(&o.stdout).trim().to_string())
    };
    let sha = match git(&["rev-parse", "HEAD"]) {
        Some(s) if !s.is_empty() => {
            let dirty = git(&["status", "--porcelain"]).map(|s| !s.is_empty()).unwrap_or(false);
            if dirty { format!("{s}-dirty") } else { s }
        }
        _ => std::fs::read_to_string(root.join(".git-rev")).map(|s| s.trim().to_string())
            .unwrap_or_else(|_| "unknown".into()),
    };
    println!("cargo:rustc-env=RAND_GIT_SHA={sha}");
    println!("cargo:rerun-if-changed={}", root.join(".git/HEAD").display());
    println!("cargo:rerun-if-changed={}", root.join(".git-rev").display());
}
```

pub fn receipts_index_built(&self) -> Result<bool> {
    Ok(self.get_meta_raw(META_RECEIPTS_INDEX_BUILT)?.is_some())
}

/// Builds `receipts_by_program` from `receipts` once. The marker, not the family's
/// emptiness, is the guard, so a node killed mid-backfill finishes on its next open.
fn backfill_receipts_index(&self) -> Result<()> {
    if self.receipts_index_built()? {
        return Ok(());
    }
    let mut batch = WriteBatch::default();
    let mut n = 0u64;
    for item in self.db.iterator_cf(self.cf(CF_RECEIPTS), IteratorMode::Start) {
        let (_, v) = item?;
        let r: CallReceipt = bincode::deserialize(&v)?;
        batch.put_cf(self.cf(CF_RECEIPTS_BY_PROGRAM), receipt_index_key(&r.program, r.height, r.index), r.tx.as_bytes());
        n += 1;
        if n % 1_000 == 0 {
            self.db.write(std::mem::take(&mut batch))?;
        }
    }
    batch.put_cf(self.cf(CF_META), META_RECEIPTS_INDEX_BUILT.as_bytes(), [1u8]);
    self.db.write(batch)?;
    if n > 0 {
        tracing::info!("built the receipts-by-program index from {n} receipts");
    }
    Ok(())
}

pub fn receipts_for_program(&self, program: &ProgramId, from: u64, to: u64, limit: usize) -> Result<(Vec<CallReceipt>, Option<u64>)> {
    let start = receipt_index_key(program, from, 0);
    let mut out = Vec::new();
    let mut next = None;
    for item in self.db.iterator_cf(self.cf(CF_RECEIPTS_BY_PROGRAM), IteratorMode::From(&start, Direction::Forward)) {
        let (k, v) = item?;
        if k.len() != 44 || &k[..32] != program.as_bytes() { break; }
        let height = u64::from_be_bytes(k[32..40].try_into().unwrap());
        if height > to { break; }
        if out.len() >= limit { next = Some(height); break; }
        let tx = Hash(v[..].try_into().map_err(|_| StorageError::Corrupt("receipt index value".into()))?);
        if let Some(r) = self.receipt(&tx)? { out.push(r); }
    }
    Ok((out, next))
}
```
`Direction` comes from `rocksdb::Direction`; check the existing imports. `ProgramId` is `randprotocol_core::program::ProgramId` (already imported for `program()`).

Note the `next` semantics: the resume height is the height of the first receipt that did not fit, and the client re-requests from it. A page boundary inside one height re-serves that height's earlier receipts; document it in Task 3's `rpc.md` text ("pages resume at a height, so a client de-duplicates by `tx`").

/// Paths for many leaves from one tree build (`rand_getWitnesses`); `None` for an index past
/// the tree. The root is the same for every path, so it is returned once.
pub fn witnesses(&self, indices: &[u64], executor: &dyn ConfidentialExecutor) -> Result<(Word8, Vec<Option<[Word8; DEPTH]>>)> {
    let leaves = self.leaves()?;
    let len = leaves.len() as u64;
    let tree = FullTree::new(leaves, executor);
    let paths = indices.iter().map(|&i| if i < len { tree.path(i) } else { None }).collect();
    Ok((tree.root(), paths))
}

fn parse_topic(params: &Value) -> Result<Topic, String> {
    match params.get(0).and_then(Value::as_str) {
        Some(NEW_HEADS) => Ok(Topic::NewHeads),
        Some(RECEIPTS) => match params.get(1) {
            None | Some(Value::Null) => Ok(Topic::Receipts(None)),
            Some(v) => v.as_str().and_then(|s| ProgramId::from_hex(s).ok()).map(|p| Topic::Receipts(Some(p)))

        Some(other) => Err(format!("unknown subscription topic {other}; this node serves {TOPICS}")),
        None => Err(format!("rand_subscribe takes a topic: {TOPICS}")),

fn commit_frames(subs: &mut BTreeMap<String, Topic>, c: &CommitSummary) -> Vec<String> {
    let mut out = Vec::new();
    let mut done = Vec::new();
    for (id, topic) in subs.iter() {
        match topic {
            Topic::Receipts(filter) => {
                let rows: Vec<Value> = c.receipts.iter().filter(|r| filter.map_or(true, |p| r.program == p)).map(crate::rpc::receipt_json).collect();
                if !rows.is_empty() {

            Topic::NewHeads => {}
        }
    }
    for id in done { subs.remove(&id); }
