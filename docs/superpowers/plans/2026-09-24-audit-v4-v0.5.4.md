- Amounts in RPC JSON are decimal strings.

## Review Focus

1. A validator whose lock is above the head restarts before `META_LOCKED_BLOCK` was written (lock advanced, crash before persist): it must fetch as today, never panic, never lower the lock — Task 4 pins `resume` with a `locked_qc` and no stored block.
2. A `NotHeld` reply from a peer that is a validator in a *previous* epoch set but not the current one must count nothing — Task 4's off-set test.
3. A proposal exactly `PROPOSAL_VIEW_WINDOW` ahead while this replica is far behind (syncing after downtime): it must be refused without being treated as an equivocation and the replica must still catch up through NewViews/QCs — Task 3's window test asserts `ViewTooFarAhead`, not `Equivocation`, and the existing sync tests stay green.
4. A `Mint` in the last block of an epoch under the faucet budget, followed by one in the first block of the next: the counter resets on the epoch boundary as the ledger computes it (`height / epoch_blocks`), never on wall time — Task 6's boundary test.
5. A rolling-window mint exactly at `cap_window_secs` after an earlier one: the earlier amount has left the window (strict `>`), so the cap admits it — Task 7's boundary test.

```rust
//! Free space on the filesystem holding the data directory (audit v4 OPS-3).
use std::path::Path;

/// Bytes available to this process on `path`'s filesystem (`f_bavail * f_frsize`).
pub fn free_bytes(path: &Path) -> std::io::Result<u64> {
    use std::os::unix::ffi::OsStrExt;
    let c = std::ffi::CString::new(path.as_os_str().as_bytes())
        .map_err(|e| std::io::Error::new(std::io::ErrorKind::InvalidInput, e))?;
    let mut st: libc::statvfs = unsafe { std::mem::zeroed() };
    // SAFETY: `c` is a valid NUL-terminated path and `st` is a zeroed out-parameter.
    if unsafe { libc::statvfs(c.as_ptr(), &mut st) } != 0 {
        return Err(std::io::Error::last_os_error());
    }
    Ok(st.f_bavail as u64 * st.f_frsize as u64)
}

/// Free space under this many times the startup minimum is reported as `disk_low`.
pub const DISK_LOW_FACTOR: u64 = 4;
```
