# RPL-3 Perpetuals: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A perpetual-futures exchange on Rand whose orders enter through consensus without being executed, whose engine runs inside the Rand zkVM, and whose state root advances only when a permissionless prover submits a verified proof — reachable from `durian.market/perps`.

**Architecture:** Chain side ("RPL-3", `fullnode` branch `feat/rpl3`): six new bundle-less-or-bundled actions (`PerpDeposit`, `PerpOrder`, `PerpCancel`, `PerpWithdraw`, `PerpOracle`, `PerpStateProof`), a `ledger/perps.rs` module that records orders and computes a per-block input digest `D_h` and a stake-weighted oracle median at block close, and a `PerpStateProof` admission that verifies one STARK over the public segment `[version, from, to, R_from, R_to, payouts_digest, fees, D_{from+1..to}]` and advances the proved root. Engine side (`durian.market` branch `feat/perps`): `perp-core` (a `no_std`, no-panic, no-division engine: book, matching, clearinghouse, funding, liquidation), `perp-guest` (the zkVM program: recompute `R_from` from the witnessed state, recompute each `D_h`, run the engine, pin `R_to` and the payouts digest), `perp-prover` (a daemon that replays the chain, builds the witness, hands it to `rand perp prove`, and serves the optimistic state over HTTP), and a `/perps` page in `web/`.

**Tech Stack:** Rust 1.98.1 (edition 2021 in `fullnode`/`durian.market`, as the existing crates), Plonky3 batch STARK via the vendored `rand_zkvm` (`crates/randprotocol-zkvm`), `riscv32im-unknown-none-elf` guests through `rand-guest`, Next.js 15 / React 19 / Tailwind 4 / Vitest in `web/`.

**Spec:** `/Users/dendisuhubdy/Github/randprotocol/references/src/07-perp-dex-on-rand.md` (§6 "The design", §7 "What the zkVM needs"). This plan implements the v0 of that design: S1 as a whole-state hash (not yet a Merkle tree), S2 deferred (the engine stays small enough to hash per proof), S3 in full, S4(a) one proof per window of ≤ `max_window_blocks` blocks, S5 in full minus the prover register and payment, S6 not needed.

## Global Constraints

- Rust toolchain `1.98.1` (every workspace pins it in `rust-toolchain.toml`; `durian.market` has none and calls `cargo +1.98.1` explicitly in scripts — keep that).
- `cargo fmt --all -- --check`, `cargo clippy --all-targets --all-features -- -D warnings`, `cargo test --workspace --locked` must pass in `fullnode` before every commit. `durian.market`: `cargo test` for the Rust crates, `npm run lint && npm run typecheck && npm test` in `web/`.
- **No path dependency into a sibling submodule** (`fullnode/README.md`, "Vendoring"). `durian.market` talks to the node over RPC and to the prover over the `rand` binary as a subprocess, exactly as `durian-cli` runs `rand program invoke`.
- **A guest must contain no panicking path**: `scripts/build-guest.sh`'s `llvm-nm` gate (`panic|unwind|core..fmt|bounds_check|slice_index`) applies to `perp-guest`. No `unwrap`, no indexing without `.get()`, no `/` or `%` on a divisor that is not a non-zero constant: use `checked_div`.
- **New `Action` variants are appended after `Invoke` (33)** at tags 34–39, in the order listed in Task 2; `VARIANTS`, `variant_index`, `sample` and `blanked` are updated in the same commit (`transaction.rs:1613-1660`).
- **Everything is genesis-gated** on a `perps` section. Without it every new action is refused as `TxError::UnsupportedAction("perps")` before any other check, and the state root is byte-for-byte unchanged (`rand-state-8` stays; `rand-state-9` only with the section).
- Hash domains (first word of the Poseidon2 sponge, `notes::hash(domain, msg)` = `sponge_hash([domain, msg…])`): `PERP_BLOCK = 21`, `PERP_STATE = 22`, `PERP_PAYOUTS = 23`. Reserved in `crates/randprotocol-zkvm/src/notes.rs`'s `domain` module (16 is the last one in use).
- Word encodings: every `u64` is two `u32` words, low first. Every `Word8` is 8 words in order. Hex strings on the wire are 64 hex chars, each word as 8 LE hex chars (the existing `word8_to_hex`).
- Signed messages: `Hash::digest_domain(b"rand-perp-sign-1", &bincode::serialize(&(chain_id, kind_tag, body)))` where `kind_tag` is the action's tag (35, 36, 37, 38) and `body` is the action with `signature` replaced by `Signature::empty()`.
- Collateral is the genesis `perps.collateral_asset` (0 = RAND via `burn_r`; otherwise a registered token via `burn_a`/`burn_asset`). The devnet uses 0; testnet uses zUSD (1).

## Review Focus

Inputs the spec implies but no single task's happy path exercises; each line names the owning task, which carries the test.

1. **An order from an account that has never deposited** — refused with `PerpError::UnknownAccount`, never creates state. (Task 3.)
2. **A `PerpStateProof` whose `from_height` is not the proved height, or whose window skips a height with no recorded digest** — refused (`PerpError::WindowMismatch`); the ledger never trusts a prover's claim of which blocks it covered. (Task 4.)
3. **A payout for a withdrawal request the ledger does not hold, or larger than requested** — refused before the proof is verified. (Task 4.)
4. **A `PerpOracle` from a key that is not in the current validator set, or replaying an old nonce** — refused; the median never moves. (Task 3.)
5. **An order that would overflow `size × price` or exceed the engine's capacity caps** — the engine refuses it and the block still proves (the refusal is itself part of the proved transition), never traps. (Task 8.)

## Protocol definitions (used verbatim by every task)

### Word encodings of inputs (`PerpInput::words`)

```
Deposit   [1, account(8), amount_lo, amount_hi]                                              11 words
Order     [2, account(8), nonce_lo, nonce_hi, market, side, kind, tif, reduce_only,
           price_lo, price_hi, size_lo, size_hi]                                             20 words
Cancel    [3, account(8), nonce_lo, nonce_hi, target_lo, target_hi]                          15 words
Withdraw  [4, account(8), nonce_lo, nonce_hi, amount_lo, amount_hi, request(8)]              23 words
Close     [5, height_lo, height_hi, time_ms_lo, time_ms_hi, n_markets,
           (market, median_lo, median_hi)*]                                                  6 + 3·n
```
`side`: 0 buy, 1 sell. `kind`: 0 limit, 1 market. `tif`: 0 GTC, 1 IOC, 2 post-only. `reduce_only`: 0/1. A block's input words are the concatenation of its inputs in block order, then exactly one `Close`. `D_h = perp_digest(PERP_BLOCK, words)`.

### `perp_digest(domain, words)` (ledger via the executor; guest via `poseidon2`)

```
acc = H(domain, [len(words) as u32])                       // H(d, m) = sponge over [d, m…]
for chunk in words.chunks(4000):                           // 1 + 8 + 4000 ≤ 4096, the syscall's cap
    acc = H(domain, acc(8) ‖ chunk)
return acc
```

### `PerpStateProof` public segment (`perps::state_proof_segment`)

```
[PERP_VERSION=1, from_lo, from_hi, to_lo, to_hi,
 R_from(8), R_to(8), payouts_digest(8), fees_lo, fees_hi, n_blocks,
 D_{from+1}(8), …, D_to(8)]
payouts_digest = perp_digest(PERP_PAYOUTS, [n, (request(8), amount_lo, amount_hi)*])
```

### Guest private witness

```
[n_state, state_words…, n_blocks, (n_words, block_words…)*]
```

### Guest outputs (`write_output`)

`[PERP_VERSION, n_blocks, n_orders, n_fills, n_liquidations, n_payouts, 0, 0]`.

### Account id

`AccountId = Word8 = word8_from_bytes(Address::from_public_key(trading_key).as_bytes())`.

### Nonce rule (orders, cancels, withdrawals)

Per account: `nonce_high: u64`, `used: u64` (a bitmap over `nonce_high-63..=nonce_high`). A nonce `n` is accepted iff `n > nonce_high` (then `used <<= (n - nonce_high)` saturating to 0 past 63, `nonce_high = n`, set bit 0) or `nonce_high - 63 <= n <= nonce_high` with bit `nonce_high - n` clear (then set it). Otherwise `PerpError::NonceUsed`.

### Engine constants (`perp-core`)

```rust
pub const MAX_MARKETS: usize = 2;
pub const MAX_ACCOUNTS: usize = 16;
pub const MAX_ORDERS: usize = 32;          // resting orders, all markets
pub const MAX_WITHDRAWS_PER_WINDOW: usize = 8;
pub const BASE_UNIT: u64 = 1_000_000_000;   // size is in base atomic units; price is quote atomic per BASE_UNIT base
pub const FUNDING_PERIOD_MS: u64 = 8 * 3_600_000;
pub const FUNDING_CLAMP_BPS: u64 = 50;
```

### Engine state encoding (`State::encode`)

```
[1 (version), next_order_seq_lo, next_order_seq_hi, insurance_lo, insurance_hi, fees_lo, fees_hi,
 n_markets, Market*, n_accounts, Account*, n_orders, Order*]
Market  = [id, lot_lo, lot_hi, tick_lo, tick_hi, max_leverage, maintenance_bps, taker_fee_bps, maker_fee_bps,
           funding_index_lo, funding_index_hi (i64 as u64 two's complement), last_oracle_lo, last_oracle_hi,
           last_funding_ms_lo, last_funding_ms_hi]                                           15 words
Account = [id(8), collateral_lo, collateral_hi, nonce_high_lo, nonce_high_hi, used_lo, used_hi,
           Position × MAX_MARKETS]
Position = [size_lo, size_hi (i64), entry_notional_lo, entry_notional_hi, funding_index_lo, funding_index_hi] 6 words
Order   = [seq_lo, seq_hi, account_index, market, side, nonce_lo, nonce_hi, price_lo, price_hi, remaining_lo, remaining_hi, reduce_only] 12 words
```
`R = perp_digest(PERP_STATE, encode(state))`. The genesis state is `State::genesis(&[MarketSpec])`: counters 0, no accounts, no orders.

Rules:
- **Deposit**: find or create the account (refuse silently if `n_accounts == MAX_ACCOUNTS`); `collateral = collateral.checked_add(amount)` else refuse.
- **Nonce** per the protocol rule; a used nonce makes the whole input a no-op.
- **Order**: validate shape (as the ledger does, repeated here because the guest must not trust the ledger); market order ⇒ `price = u64::MAX` for buys / `0` for sells, `tif = IOC`; post-only that would cross ⇒ refuse; then match: while `remaining > 0` and best opposite exists and crosses (`buy: best_ask ≤ price`, `sell: best_bid ≥ price`): `fill = min(remaining, best.remaining)`; **margin check on the taker and the maker after the fill** at the fill price (`equity ≥ initial_margin` with the new position; if the taker fails, stop matching and drop the remainder; if the maker fails, cancel the maker's order and continue); apply the fill to both positions (`apply_fill(pos, side, size, price)`: same direction → `entry_notional += notional`, `size += ±fill`; reducing → realised pnl = `notional(fill, price) - entry_notional·fill/|size|` with sign, `entry_notional -= entry_notional·fill/|size|` (checked_div on `|size|` which is non-zero in this branch), collateral `+=` pnl (clamped at zero: a loss beyond collateral becomes bad debt → `insurance = insurance.saturating_sub(debt)`); fees: taker pays `notional·taker_bps/10_000`, maker `maker_bps`, into `state.fees`; `reduce_only` orders fill only while they reduce. Remainder: GTC/post-only ⇒ rest in the book (refuse if `n_orders == MAX_ORDERS`), IOC ⇒ drop. Book order: bids by `(price desc, seq asc)`, asks by `(price asc, seq asc)`; keep `orders` as an unsorted array and select best by linear scan (32 entries: cheap and no sort needed in the guest).
- **Cancel**: remove the order with `(account, nonce == target)`.
- **Withdraw**: `free = equity - initial_margin` (both at the current marks = `last_oracle`); if `amount ≤ free` and `amount ≤ collateral` ⇒ `collateral -= amount`, push `Payout { request, amount }`; else push `Payout { request, amount: 0 }`. If `push_payout` is full ⇒ refuse (no payout; the request stays pending on the chain until a later window — **documented limit**).
- **Close**: for each market with a non-zero median: `mark = median`; funding: `mid = (best_bid + best_ask)/2` if both exist else `mark`; `premium = clamp(mid - mark, ±mark·FUNDING_CLAMP_BPS/10_000)`; `delta = premium·(time_ms - last_funding_ms)/FUNDING_PERIOD_MS` (i128, checked); `funding_index += delta`; `last_funding_ms = time_ms`; `last_oracle = mark`. Lazy settlement: whenever a position is touched (fill, liquidation, equity) its accrued funding is `-size·(market.funding_index - pos.funding_index)/BASE_UNIT`, added to collateral and `pos.funding_index` reset. Liquidation: for each account, if `equity < maintenance_margin`: for each market with a position, close it by a market order against the book as a taker (fees as taker, counterparties as makers); any residual position is closed against the insurance fund at the mark (pnl moves between collateral and insurance); a liquidation fee of `maintenance_bps/2` of notional goes to insurance; `n_liquidations += 1`. Accounts are scanned in index order so the result is deterministic.
- **No ADL, no backstop vault, no fee split** in v0 (documented).

```rust
#![no_std] #![no_main]
use guest_sdk::{halt, poseidon2, read_input, read_public, write_output};
use perp_core::{apply_block, Outcome, State, MAX_WITHDRAWS_PER_WINDOW};
const PERP_VERSION: u32 = 1; const DOM_BLOCK: u32 = 21; const DOM_STATE: u32 = 22; const DOM_PAYOUTS: u32 = 23;
const CHUNK: usize = 4000;
static mut BUF: [u32; 1 + 8 + CHUNK] = [0; 1 + 8 + CHUNK];        // one hashing buffer; guests are single-threaded
static mut STATE_WORDS: [u32; State::MAX_WORDS] = [0; State::MAX_WORDS];
static mut BLOCK_WORDS: [u32; 8192] = [0; 8192];                   // per-block input cap; a longer block refuses

fn digest(domain: u32, words: &[u32]) -> [u32; 8] { /* acc = H(domain,[len]); for chunk: acc = H(domain, acc‖chunk) via poseidon2(BUF.as_mut_ptr(), 1+8+chunk.len()) */ }
fn pub8(i: u32) -> [u32; 8] { [read_public(i), …, read_public(i+7)] }
fn refuse() -> ! { read_input(u32::MAX); loop {} }

#[no_mangle] pub extern "C" fn main() -> ! {
    let version = read_public(0);
    let echo = version == 0xFFFF_FFFF;
    if !echo && version != PERP_VERSION { refuse() }
    let n_blocks_pub = read_public(31);
    let r_from = pub8(5); let r_to = pub8(13); let payouts_pub = pub8(21); let fees_pub = (read_public(29) as u64) | ((read_public(30) as u64) << 32);
    // witness
    let n_state = read_input(0) as usize; if n_state > State::MAX_WORDS { refuse() }
    for i in 0..n_state { STATE_WORDS[i] = read_input(1 + i as u32) }
    let computed_from = digest(DOM_STATE, &STATE_WORDS[..n_state]);
    let mut state = State::decode(&STATE_WORDS[..n_state]).unwrap_or_else(|| refuse());   // write this as match { Some(s) => s, None => refuse() }
    let mut cursor = 1 + n_state as u32;
    let n_blocks = read_input(cursor); cursor += 1;
    if !echo && n_blocks != n_blocks_pub { refuse() }
    let mut out = Outcome::default();
    let mut first_digest = [0u32; 8];
    for b in 0..n_blocks {
        let n = read_input(cursor) as usize; cursor += 1; if n > BLOCK_WORDS.len() { refuse() }
        for i in 0..n { BLOCK_WORDS[i] = read_input(cursor + i as u32) } cursor += n as u32;
        let d = digest(DOM_BLOCK, &BLOCK_WORDS[..n]);
        if b == 0 { first_digest = d }
        if !echo && d != pub8(32 + 8 * b) { refuse() }
        if apply_block(&mut state, &BLOCK_WORDS[..n], &mut out).is_none() { refuse() }
    }
    let n_after = match state.encode(&mut STATE_WORDS) { Some(n) => n, None => refuse() };
    let computed_to = digest(DOM_STATE, &STATE_WORDS[..n_after]);
    // payouts digest: [n, (request(8), lo, hi)*]
    let pw = payout_words(&out);  let computed_payouts = digest(DOM_PAYOUTS, pw);
    if echo { /* run 1 (read_public(1)==0): outputs = computed_from; run 2 (==1): computed_to; run 3 (==2): first_digest; run 4 (==3): computed_payouts */ halt() }
    if computed_from != r_from || computed_to != r_to || computed_payouts != payouts_pub || out.fees != fees_pub { refuse() }
    write_output(0, PERP_VERSION); write_output(1, n_blocks); write_output(2, out.n_orders); write_output(3, out.n_fills);
    write_output(4, out.n_liquidations); write_output(5, out.n_payouts as u32); write_output(6, 0); write_output(7, 0);
    halt()
}
```
